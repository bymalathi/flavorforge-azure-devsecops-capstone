# 🍽️ FlavorForge - Enterprise Azure DevSecOps Capstone

> **Production-style Azure DevSecOps project demonstrating a complete CI/CD pipeline using Azure DevOps, Docker, Azure Container Registry (ACR), Azure Kubernetes Service (AKS), Kubernetes, SonarCloud, Trivy, and Azure Monitor.**

---

# 📌 Project Overview

FlavorForge is a modern recipe-sharing platform built as an Enterprise Azure DevSecOps Capstone.

The goal of this project is not only to build a web application but to demonstrate how modern applications are designed, containerized, secured, deployed, monitored, and continuously delivered using Azure cloud services and Kubernetes.

This repository follows production-inspired DevOps practices including structured documentation, Infrastructure as Code concepts, containerization, Kubernetes deployments, CI/CD automation, security scanning, and monitoring.

---

# 🎯 Project Objectives

- Build a modern full-stack application
- Containerize the application using Docker
- Deploy workloads to Azure Kubernetes Service (AKS)
- Implement a multi-stage Azure DevOps pipeline
- Store container images in Azure Container Registry (ACR)
- Perform code quality analysis using SonarCloud
- Scan container images using Trivy
- Monitor workloads using Azure Monitor and Container Insights
- Follow enterprise repository structure and documentation standards
